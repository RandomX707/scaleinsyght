# Phase 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement private saved-question reuse, evidence-backed report snapshots and exports, and approved governed-agent daily schedules using the existing PostgreSQL runner and worker.

**Architecture:** Preserve existing plan/run storage and personal-memory ownership. Add a `reports` schema with RLS-protected definitions, append-only snapshots/export metadata, and due schedule slots. Revalidate authorization at dispatch time. Generate PDF/XLSX/PPTX from a single typed safe evidence-pack document so every format reproduces identical figures.

**Tech stack:** TypeScript, Fastify, React, PostgreSQL 16/RLS, Vitest/Playwright; synthetic fixtures only.

- `tests/contracts/c1_saved_questions_reports.test.ts`, `c3_saved_question_revalidation.test.ts`, `c4_evidence_pack_exports.test.ts`, `c5_scheduled_reports.test.ts`, `tests/e2e/phase5.spec.ts`: behavioral and browser gates.
