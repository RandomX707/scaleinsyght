| 40 | Ordered and limited single-table group-by | decided | The `group_by` intent gains optional `orderBy` (`value` or `group`), `order` and `limit` (1 to 100), so "top N by total" on one table or sheet needs no join. | 41 | Sensitivity tags inferred from names and value formats | decided | Every connector keeps the tags its source declares (a column comment, an extended property, a workbook header note) and adds tags inferred from the column name or the format of a bounded value sample (phone and email formats, unique letter-and-digit record codes). Inference can only add tags, so it can only increase what is withheld; the model boundary still enforces tags (non-negotiable 5, contract 7). Each tag stores its evidence: declared or inferred, with the reason, shown in Profile and Dictionary. Samples are read in process, discarded, and never stored or sent to a model; out-of-scope objects are never sampled. Rules are industry-neutral; record codes are recognised by format, not by vocabulary. Review of inferred tags in the Approval matrix is built with that screen in S6. Alternatives considered: declared tags only (an untagged workbook would expose sensitive statistics); inference for workbooks only (databases without comments would differ). | Yashaswi, 24 Nov 2026 |
